# Безопасность и приватность

## Аутентификация и авторизация
- JWT + OAuth2 для всех API
- Шифрование паролей и чувствительных данных (bcrypt, Argon2)
- Rate limiting и защита от brute-force
- Ротация токенов и автоматический logout

## Хранение данных
- Минимизация персональных данных (privacy by design)
- SecurePrefs на мобильном для токенов и приватных данных
- Шифрование данных в PostgreSQL (pgcrypto)
- Регулярные бэкапы и мониторинг доступа

## RAG и ML
- Локальное хранение и обработка данных (без утечек наружу)
- Контент-фильтры для генерации
- Логирование обращений к ML-модулям
- Ограничение доступа к ML через ACL

## Защита API
- OpenAPI security schemes (Bearer, OAuth2)
- CORS и CSRF protection
- Валидация входных данных
- Мониторинг и алерты по подозрительным действиям

## Соответствие стандартам
- GDPR-ready: право на удаление, экспорт, ограничение обработки
- Privacy Policy и Terms of Service для пользователей
- Регулярные аудиты безопасности
