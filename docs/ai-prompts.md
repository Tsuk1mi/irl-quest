# AI-промпты и взаимодействие с локальными ML решениями

## Основные сценарии
- Генерация квестов и задач
- Создание тестов по теме или документу
- Генерация описаний, наград, боссов

## Примеры промптов
- "Сгенерируй квест для задачи: [описание задачи]"
- "Создай тест по теме: [название темы]"
- "Опиши награду за выполнение: [описание достижения]"
- "Сгенерируй босса для челленджа: [описание цели]"

## Best practices
- Используйте структурированные промпты: четко указывайте формат ответа
- Для RAG — добавляйте контекст из векторной базы (pgvector)
- Логируйте все обращения к ML для аудита
- Ограничивайте длину и сложность промптов для стабильной работы моделей

## Локальные ML решения
- Генерация и обработка на собственных серверах
- Использование pgvector для поиска релевантных фрагментов
- RAG: retrieval-augmented generation через локальные модели

## Примеры интеграции
- Backend отправляет промпт в ML-сервис через gRPC/OpenAPI
- ML-сервис возвращает результат, backend сохраняет его в pgvector
