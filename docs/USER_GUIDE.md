# 📱 IRL Quest - Руководство пользователя

## 🏰 Добро пожаловать в Гильдию Искателей Приключений!

IRL Quest - это мобильное приложение, которое превращает ваши повседневные задачи в эпические приключения в стиле D&D. Каждое выполненное дело приносит опыт, золото и приближает вас к новому уровню!

---

## 🚀 Быстрый старт

### 1. Первый запуск
1. Откройте приложение
2. На экране входа нажмите "📝 Зарегистрировать нового героя"
3. Заполните:
   - 📧 Email
   - ⚔️ Имя героя (логин)
   - 🔐 Секретное слово (пароль)
4. Нажмите "🎉 Вступить в Гильдию"

### 2. Вход
1. Введите имя героя и пароль
2. Нажмите "⚔️ Войти в таверну"
3. (DEV режим: кнопка "🧙 DEV: Быстрый вход")

---

## 🎮 Основные разделы

### 🏰 Таверна (Главный экран)

Центр вашего игрового мира:

#### 📊 Карточка персонажа
- **Имя и уровень**: Ваш текущий ранг
- **XP прогресс**: Полоса опыта до следующего уровня
- **Золото**: Накопленная валюта
- **Ранг**: Новичок → Искатель → Герой → Чемпион → Легенда

#### 📜 Доска квестов
- Горизонтальный список активных квестов
- Показывает прогресс выполнения
- Клик на квест → детали и задачи

#### ✅ Задания дня
- Список текущих задач
- Чекбокс для выполнения
- Показывает награды (⭐ XP, 💰 золото)
- Кнопки:
  - **✓ Готово** - завершить задачу
  - **↶ Вернуть** - отменить выполнение
  - **🗑️ Удалить** - удалить задачу

---

### ✅ Создание задания

1. Нажмите золотую кнопку **+** внизу экрана
2. Заполните форму:

#### ⚔️ Название подвига
Краткое название задачи (обязательно)
```
Примеры:
- Изучить Kotlin
- Купить продукты
- Пробежка 5 км
```

#### 📖 Описание (опционально)
Детали задачи
```
Примеры:
- Разобраться с основами Kotlin
- Молоко, хлеб, яблоки
- Пробежать 5 км в парке
```

#### ⏰ Дедлайн (опционально)
Формат: дд.мм.гггг
```
Примеры:
- 25.10.2025
- 31.12.2025
```

#### 🎯 Приоритет
- 🔵 **Низкий** - рутинные дела
- 📌 **Средний** - обычные задачи
- 🔥 **Высокий** - важные дела
- ⚡ **Критический** - срочно и важно

#### 🎲 Сложность (1-5)
- 🥉 **1 - Легко**: быстрые простые дела (5-15 мин)
- 🥈 **2 - Средне**: обычные задачи (30-60 мин)
- 🥇 **3 - Сложно**: требуют усилий (1-2 часа)
- 🥇 **4 - Героически**: серьёзные задачи (2-4 часа)
- ⚡ **5 - Легендарно**: эпические свершения (4+ часа)

#### 🤖 Пусть ИИ выберет сложность
Поставьте галочку - ИИ проанализирует текст и определит сложность автоматически

#### 🎁 Превью наград
Показывает сколько опыта и золота получите за выполнение

3. Нажмите **⚔️ Принять задание**

---

### 🎁 Система наград

При нажатии ✅ на задаче появляется диалог:

```
╔════════════════════════════╗
║    ✨  ✓  ✨              ║
║                            ║
║ ⚔️ Квест Завершен! ⚔️     ║
║                            ║
║ «Название задачи»          ║
║                            ║
║ ⭐ Получено опыта          ║
║    +30 XP                  ║
║                            ║
║ 💰 Получено золота         ║
║    +30                     ║
║                            ║
║ "Гильдия гордится тобой!"  ║
╚════════════════════════════╝
```

**Что происходит:**
- ✅ Задача помечается выполненной
- ⭐ Опыт добавляется к вашему профилю
- 💰 Золото добавляется
- 📈 XP бар обновляется
- 🎉 Если достаточно XP → повышение уровня!

#### Формула наград:
```
XP = (сложность × 10) + бонус_приоритета
Золото = сложность × 10

Бонусы приоритета:
⚡ Критический: +20 XP
🔥 Высокий: +10 XP
📌 Средний: +5 XP
🔵 Низкий: +0 XP

Примеры:
Задача сложности 3, приоритет Высокий:
→ XP = (3 × 10) + 10 = 40 XP
→ Золото = 3 × 10 = 30 💰
```

### 📜 Квесты

Квесты - это группы связанных задач с общей целью.

#### Создание квеста:
1. Перейдите в раздел "📜 Квесты"
2. Нажмите золотую кнопку **+** внизу справа
3. Заполните:
   - **⚔️ Название приключения**
   - **📖 Легенда квеста** (опционально)
   - **🎯 Сложность** (1-5)
4. Увидите превью наград
5. Нажмите **🎉 Принять квест**

#### Фильтры квестов:
- **Все** - все квесты
- **Активные** - в процессе
- **Завершённые** - выполненные
- **Важные** - высокий приоритет
- **Просроченные** - с истекшим дедлайном

#### Детали квеста:
- Клик на квест → список подзадач
- Прогресс выполнения
- Общая награда
- Чекбоксы для подзадач

## 🤖 ИИ-функции

### 🎭 ML-генерация приключений ⭐ НОВОЕ!

**Каждая задача автоматически превращается в D&D квест!**

#### Как это работает:

1. **Вы создаёте обычную задачу**:
   ```
   Название: "Купить продукты"
   Описание: "Молоко, хлеб, яблоки"
   ```

2. **ML автоматически создаёт фэнтези-версию**:
   ```
   📜 Название: "🏆 Поиски артефакта: Купить Продукты"
   
   📖 Описание:
   "В мистическом царстве продуктивности ждёт великое испытание.
   Древние свитки гласят о «купить продукты».
   
   Только герой твоего калибра может взяться за этот простой квест.
   Королевство зависит от твоего успеха, отважный искатель приключений!
   
   📜 Детали: Молоко, хлеб, яблоки"
   ```

3. **На главном экране видите квест**:
   - По умолчанию показывается фэнтези-версия
   - Оригинальная задача сохранена
   - Клик откроет детали

#### Примеры генерации:

```
"Сделать отчёт" 
→ "📜 Хроники: Сделать Отчёт"

"Изучить Kotlin"
→ "⚔️ Священная миссия: Изучить Kotlin"

"Пробежка 5 км"
→ "✨ Пророчество: Пробежка 5 Км"

"Позвонить клиенту"
→ "⭐ Легенда о герое: Позвонить Клиенту"
```

#### Шаблоны названий:
- ⚔️ "Священная миссия: {}"
- 🏆 "Поиски артефакта: {}"
- 📜 "Хроники: {}"
- ⭐ "Легенда о герое: {}"
- ✨ "Пророчество: {}"

### Автоматическое определение сложности

Включите "🤖 Пусть ИИ выберет сложность":

**ИИ анализирует**:
- Длину текста
- Ключевые слова
- Контекст задачи

**Примеры**:
```
"Быстро купить молоко"
→ ИИ определяет: 🥉 Легко (1)

"Изучить основы Kotlin и написать первое приложение"
→ ИИ определяет: 🥇 Сложно (3-4)

"Подготовить и защитить дипломную работу"
→ ИИ определяет: ⚡ Легендарно (5)
```

### Автоматические теги

ИИ распознаёт категории:
- **работа** - проект, офис, работа
- **обучение** - учить, изучить, курс, читать
- **здоровье** - спорт, тренировка, здоровье
- **дом** - уборка, чистка, домашний
- **покупки** - магазин, купить, продукты
- **готовка** - готовить, приготовить, кухня

## ❓ Часто задаваемые вопросы

### Как получить больше опыта?
- Выполняйте сложные задачи (больше XP)
- Выбирайте высокий приоритет (+бонус XP)
- Создавайте квесты с подзадачами

### Как повысить уровень?
- Накапливайте опыт
- Уровень повышается автоматически при достижении порога
- Формула: уровень × 100 XP

### Для чего нужно золото?
- Пока накапливается
- В будущем: покупка улучшений, снаряжения, бустеров

### Как работает ИИ?
- Анализирует текст задачи
- Определяет сложность по ключевым словам
- Присваивает теги автоматически
- Работает на русском и английском

### Можно ли отменить выполнение?
- Да! Нажмите ✅ снова или кнопку "↶ Вернуть"
- Опыт и золото пока не отнимаются (в следующей версии)
