# Backend IRL Quest

## Стек
- Rust (основной сервер)
- FastAPI, Celery (асинхронные задачи, интеграция с ML)
- PostgreSQL с pgvector для векторного поиска
- Redis для кэша и очередей

## Архитектура
- Микросервисная структура: Rust-сервер, ML-сервисы, воркеры Celery
- gRPC/OpenAPI для интеграции с ML и мобильным приложением
- RAG-пайплайн для генерации и поиска

## Основные сервисы
- Авторизация и пользователи (JWT, OAuth2)
- Управление квестами, задачами, боссами
- Синхронизация с календарями и внешними сервисами
- Генерация тестов и материалов через ML
- Векторный поиск и RAG

## API
- OpenAPI спецификация генерируется автоматически
- Примеры эндпоинтов:
  - `POST /api/v1/auth/login` — вход
  - `GET /api/v1/quests` — список квестов
  - `POST /api/v1/rag/generate-quest` — генерация квеста через RAG

## Деплой и тестирование
- Docker Compose для локального запуска
- Kubernetes для продакшн-окружения
- Автотесты (unit/integration) через GitHub Actions
- Мониторинг: Prometheus, Grafana
