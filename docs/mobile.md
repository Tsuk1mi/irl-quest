# Мобильное приложение IRL Quest

## Стек
- Kotlin, Jetpack Compose
- Android

## Модули
- Квесты и задачи
- Боссы и бои
- Фокус-сессии (Pomodoro)
- Учёба и тесты
- AR/Геолокация
- Кооператив и инвентарь

## Архитектура приложения
- Модульная структура: каждый функционал — отдельный модуль
- DI через Hilt/Koin
- MVVM для разделения логики и UI
- Навигация через Jetpack Navigation
- Интеграция с backend через защищённые REST API
- Работа с push-уведомлениями и локальным кэшем

## Интеграция с backend
- Авторизация через JWT
- Синхронизация задач, квестов, достижений
- Получение и отправка данных через API
- Поддержка offline-режима (кэширование)

## AR и геолокация
- Использование ARCore для подтверждения достижений
- Геолокация для чекпоинтов и групповых активностей

## Безопасность и UX
- SecurePrefs для хранения токенов
- Защита персональных данных
- Адаптивный дизайн для разных устройств
- Поддержка accessibility
