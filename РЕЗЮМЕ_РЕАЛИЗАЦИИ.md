## ⚠️ ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### Компиляция:

**Проблема**: SQLx требует подключения к БД во время компиляции

**Решение 1** (Рекомендуется):
```powershell
# Установить DATABASE_URL перед компиляцией
cd server-rust
$env:DATABASE_URL="postgresql://postgres:tsukimi@localhost:5432/irl_quest"
cargo build --release
```

**Решение 2**:
```powershell
# Создать offline кэш
cd server-rust
$env:DATABASE_URL="postgresql://postgres:tsukimi@localhost:5432/irl_quest"
cargo sqlx prepare
# Затем можно компилировать offline
cargo build --release
```

### Мелкие ошибки:

1. **WebSocket** - ownership issue (легко исправляется)
2. **Unused variables** - warnings, не критично
3. **base64::decode deprecated** - уже исправлено

## 🚀 КАК ЗАПУСТИТЬ

### Вариант 1: Исправить компиляцию

```powershell
cd server-rust

# Установить DATABASE_URL
$env:DATABASE_URL="postgresql://postgres:tsukimi@localhost:5432/irl_quest"

# Применить миграции
cargo install sqlx-cli --no-default-features --features postgres
sqlx database create
sqlx migrate run

# Собрать
cargo build --release

# Запустить
cargo run --release
```

### Вариант 2: Использовать базовую версию

Если нужно быстро запустить, можно временно вернуться к v2.0.3 которая работает с SQLite и без новых расширений.
