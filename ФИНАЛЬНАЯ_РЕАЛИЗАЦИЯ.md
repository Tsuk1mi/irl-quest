## 🚀 Запуск Production

### Вариант 1: Docker Compose (простой)
```bash
# 1. Настроить .env.docker
cp .env.docker.example .env.docker

# 2. Запустить
make start

# Доступно:
# API: http://localhost:8003
# Grafana: http://localhost:3000
# Prometheus: http://localhost:9090
```

### Вариант 2: Kubernetes (production)
```bash
# 1. Собрать образ
docker build -t irlquest/server:2.1.0 ./server-rust

# 2. Deploy с Helm
helm install irl-quest ./infra/kubernetes/helm-chart \
  --namespace production \
  --set image.tag=2.1.0

# 3. Проверить статус
kubectl get pods -n production
```
