# 🎮 IRL Quest Mobile - Обзор функций

## ✅ Реализованные функции (готовы к использованию)

### 🏰 Таверна (Главный экран)
- **Карточка героя** с уровнем, опытом, золотом и рангом
- **Доска квестов** — прокручиваемый список активных квестов
- **Задания дня** — топ-3 задачи с возможностью выполнения прямо на главном экране
- **Быстрый доступ** к фокус-сессиям, гильдиям, кооп-миссиям, аукциону

### 📜 Квесты
- Создание квестов вручную (название, описание, сложность 1-5)
- **ML-генерация квестов** (кнопка ✨) — автоопределение сложности ИИ
- Просмотр деталей квеста, добавление задач
- **Верификация завершения** — ML может запросить тест или фото (auto-fallback если backend недоступен)
- Фильтры: все, активные, завершённые, высокий приоритет

### ✅ Задания
- Создание заданий с приоритетом (критический, высокий, средний, низкий)
- **Бросок кубов D&D** перед созданием (d20, d12, d8, d6, d4) + модификаторы
- Фэнтези-преобразование названий (автоматическое)
- Награды за выполнение: XP, золото, **случайные предметы** (Common→Legendary)
- Диалог наград с анимацией и уведомлениями о повышении уровня

### 🗺️ Карта мира
- Бумажная стилизованная карта
- Отображение квестов с привязкой к локациям
- Геолокация пользователя (если разрешение получено)
- Иконки квестов на карте (кликабельные)

### 🎭 Профиль героя
- Аватар с классом и расой
- Уровень, опыт, золото, ранг
- **D&D характеристики**: STR, INT, CHA, DEX, CON, LUCK с модификаторами
- Класс и раса (Воин, Маг, Плут, Жрец / Человек, Эльф, Дворф и др.)
- **Инвентарь** — список экипировки (топ-5 предметов)
- Достижения (заглушки, готовы к расширению)

### 📊 Статистика
- Дневная активность (графики выполненных задач)
- Общая статистика: уровень, опыт, золото
- График XP по дням
- Прогресс квестов

### ⚙️ Настройки
- **Редактирование профиля**: никнейм, аватар, биография
- Управление уведомлениями
- **Разрешение приватных IP** — отключает блокировку 192.168.x.x/10.x.x.x для локальной разработки
- Выход из аккаунта

### 🎲 Аукцион
- Просмотр инвентаря
- Выставление предметов на продажу с указанием цены
- Просмотр глобальных лотов (когда backend реализует)
- Карточки с качеством предметов (цветовое кодирование)

### 🎲 Система добычи
- **Автогенерация предметов** при завершении заданий/квестов
- 5 уровней качества: Common, Uncommon, Rare, Epic, Legendary
- Шанс дропа зависит от сложности задачи и удачи персонажа
- Случайные названия: оружие, броня, артефакты
- Показ добычи в диалоге наград

### 🎲 Кубики D&D
- Интеграция в создание заданий
- Типы костей: d20, d12, d10, d8, d6, d4
- Модификаторы (+/-)
- История бросков
- Советы на основе результата броска

- Присоединение к миссиям, управление ролями

## 🏗️ Архитектура

### Kotlin Multiplatform (KMP)
- **Shared модуль**: модели, репозитории, сетевой клиент
- **Android модуль**: UI (Jetpack Compose), ViewModels, Android-специфичная логика
- **iOS-ready**: shared модуль компилируется для iOS (нужен macOS для сборки)

### Сетевой слой
- **Ktor Client** (KMP) заменяет Retrofit
- Централизованное управление токенами через `TokenStorage`
- Автоматическая авторизация через `BaseKmpRepository`
- Graceful fallback при 404 (тонкий клиент не ломается если backend неполный)

### Состояние и данные
- **StateFlow** для реактивного UI
- ViewModels с lifecycle-aware подписками
- Локальный инвентарь (in-memory, синхронизация с backend позже)
- Прогрессивные заглушки (показываем информативные сообщения вместо крашей)

## 📞 Контакты и поддержка

При проблемах с backend (404 ошибки):
- Проверьте `BuildConfig.API_BASE_URL` в `app/build.gradle.kts`
- Для эмулятора: `http://10.0.2.2:8003/api/v1/`
- Для физического устройства: замените на IP вашей машины
- Backend должен слушать `0.0.0.0` (не `127.0.0.1`)

Приложение работает в режиме тонкого клиента — все недоступные функции отображают дружественные сообщения вместо крашей.
