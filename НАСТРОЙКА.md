## 📁 Единый файл конфигурации

Весь проект использует **ОДИН** `.env` файл в корне проекта.

```
irl-quest/
├── .env.example    ← Шаблон (не редактируйте)
├── .env            ← ВАША конфигурация (создайте)
├── server-rust/
└── mobile/
```

## 🔐 Важные параметры для изменения

### Обязательно измените перед production:

```env
# ОЧЕНЬ ВАЖНО! Сгенерируйте безопасный секрет:
JWT_SECRET=CHANGE-THIS-TO-RANDOM-STRING-64-CHARS

# Ограничьте CORS для безопасности:
CORS_ORIGIN=https://yourdomain.com

# Включите дополнительную безопасность:
ENABLE_MFA=true
PASSWORD_MIN_LENGTH=12
RATE_LIMIT_PER_MINUTE=30
```

### Как сгенерировать безопасный JWT_SECRET:

**PowerShell**:
```powershell
-join ((65..90) + (97..122) + (48..57) | Get-Random -Count 64 | % {[char]$_})
```

**Linux/Mac**:
```bash
openssl rand -base64 64
```

## 🤖 Настройка ML

Для работы ML функций нужен Ollama:

```env
# URL Ollama сервера
ML_BASE_URL=http://localhost:11434

# Опционально: команды для inference
ML_INFER_CMD=ollama run llama2
ML_EMBED_CMD=ollama embed llama2
```

**Установка Ollama**:
```bash
# Windows
winget install Ollama.Ollama

# Linux
curl https://ollama.ai/install.sh | sh

# Запуск модели
ollama pull llama2
```

## 🐳 Docker настройка

При использовании docker-compose все переменные из `.env` автоматически используются:

```bash
# Запуск всего стека
docker-compose up -d

# Остановка
docker-compose down

# Просмотр логов
docker-compose logs -f server
```

**Компоненты Docker**:
- PostgreSQL (порт 5432)
- Redis (порт 6379)
- MinIO (порты 9000, 9001)
- Rust Server (порт 8003)
- Ollama (порт 11434)
- Prometheus (порт 9090)
- Grafana (порт 3000)

## 🔍 Отладка

### Сервер не запускается?

1. **Проверьте PostgreSQL**:
   ```bash
   psql -U postgres -c "SELECT version();"
   ```

2. **Проверьте .env файл**:
   ```bash
   cat .env
   ```
   Должен содержать DATABASE_URL

3. **Проверьте порт**:
   ```bash
   netstat -an | findstr :8003
   ```
   Порт должен быть свободен

### Не подключается к БД?

```env
# Проверьте формат DATABASE_URL:
# ✅ Правильно:
DATABASE_URL=postgres://пользователь:пароль@хост:5432/база

# ❌ Неправильно:
DATABASE_URL=postgres://пользователь@хост/база  # нет пароля и порта
```

### Ошибки компиляции?

```bash
# Убедитесь что .env в корне проекта
ls -la .env

# Пересоберите
cd server-rust
cargo clean
cargo build --release
```

## ❓ FAQ

**Q: Где должен быть .env файл?**  
A: В **корне проекта** (`irl-quest/.env`), не в `server-rust/`

**Q: Можно ли использовать несколько .env файлов?**  
A: Нет, используйте один .env в корне для всего проекта

**Q: Нужно ли перезапускать после изменения .env?**  
A: Да, конфигурация загружается только при старте сервера

**Q: Как проверить что .env загружен?**  
A: Смотрите логи при запуске - будет сообщение "Loaded .env from project root"

**Q: Что делать если забыл JWT_SECRET?**  
A: Сгенерируйте новый, но все старые токены станут невалидными
